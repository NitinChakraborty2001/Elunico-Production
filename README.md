## 🛠️ Tech Stack

This is a static portfolio website built with:

| Technology | Purpose |
|-----------|---------|
| **HTML5** | Semantic page structure |
| **Tailwind CSS** (CDN) | Utility-first styling with custom dark mode |
| **Alpine.js** | Lightweight reactivity (dark mode toggle, mobile menu, scroll tracking, section highlighting) |
| **Swiper.js** | Cube-effect image carousel in the About section |
| **Google Fonts** | Typography — *PT Sans* (headings) + *DM Sans* (body) |

### Design Features

- 🌙 **Dark / Light mode** — persisted to `localStorage`, respects system preference
- ✨ **Scroll-reveal animations** — powered by `IntersectionObserver`
- 🟢 **Accent color** — `#93F205` lime-green, consistent across the brand
- 📱 **Fully responsive** — mobile-first with hamburger navigation
- 🎞️ **Showreel video** — auto-playing hero video (`EPV.mp4`)
- 📖 **Reading progress bar** — on the case study page
- 🎲 **3D Cube carousel** — 19 project images in the About section

## 🚀 Getting Started

This is a static site — no build step required.

### Option 1: Open Directly

Simply open `index.html` in your browser:

```
start index.html
```

### Option 2: Local Server (Recommended)

For best results, serve with a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Using VS Code Live Server extension
# Right-click index.html → "Open with Live Server"
```

Then visit `http://localhost:8000` in your browser.

### Option 3: Clone & Run

```bash
git clone https://github.com/NitinChakraborty2001/Elunico-Production.git
cd Elunico-Production
# Open index.html or start a local server
```
